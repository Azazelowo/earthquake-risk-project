# 生命週期階段風險評估表 (參考 Table 2-1)

| 生命週期階段 | 風險評估重點 |
|--------------|--------------|
| 需求規劃 | 需求的完整性、正確性、可追溯性；利害關係人共識度 |
| 系統分析 | 業務流程 modelling 正確性；資料需求完整性；與既有系統的介面相容性 |
| 系統設計 | 架構決策的適切性；效能、安全性、可延展性預估；技術選型風險 |
| 實作 (編程) | 程式碼品質；開發進度控制；第三方庫或工具的適用性 |
| 測試 | 測試案例覆蓋度；缺陷偵測效率；效能與安全測試充分性 |
| 部署 | 安裝與設定複雜度；資料移轉風險；運轉人員訓練與接受度 |
| 維護 | 後續需求變更應對能力；技術債累積；系統效能監控與警戒 |
