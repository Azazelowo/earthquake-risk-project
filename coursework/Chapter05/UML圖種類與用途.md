# UML 圖種類與用途

| 圖種類 | 主要用途 |
|--------|----------|
| 用例圖 (Use Case Diagram) | 描述系統功能及與參與者的互動 |
| 類別圖 (Class Diagram) | 靜態結構，顯示類別、屬性、方法及其關係 |
| 物件圖 (Object Diagram) | 類別圖的實例，展示特定時間點的物件狀態 |
| 元件圖 (Component Diagram) | 系統的組織與依賴，顯示可執行元件 |
| 部署圖 (Deployment Diagram) | 實體硬體與軟體的映射，顯示節點與元件 |
| 序列圖 (Sequence Diagram) | 時間順序的互動，顯示物件間訊息傳遞 |
| 通訊圖 (Communication Diagram) | 互動的協作關係，重視物件間連結 |
| 狀態圖 (State Diagram) | 物件在不同狀態下的行為與轉換 |
| 活動圖 (Activity Diagram) | 工作流程與業務規則的建模 |
| 配置圖 (Package Diagram) | 將模型元素組織為套件，管理依賴 |
