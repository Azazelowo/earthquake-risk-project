# Figure 7-10 Example Component Diagram for Online Shopping System

This component diagram shows the main components of an online shopping system and their dependencies.

Components:
- UserInterface: handles HTTP requests and presents web pages
- ShoppingCart: manages customer's selected items
- ProductCatalog: provides product information and search
- OrderProcessing: handles payment, inventory, and shipping
- PaymentGateway: interfaces with external payment services
- NotificationService: sends emails/SMS for order status

Dependencies:
- UserInterface --> ShoppingCart
- UserInterface --> ProductCatalog
- ShoppingCart --> OrderProcessing
- OrderProcessing --> PaymentGateway
- OrderProcessing --> NotificationService
