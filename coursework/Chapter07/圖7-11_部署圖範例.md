# Figure 7-11 Example Deployment Diagram

This deployment diagram shows the hardware topology and artifact deployment for a web application.

Nodes:
- WebServer: Apache Tomcat running on Linux
- DatabaseServer: MySQL on Windows Server
- LoadBalancer: Hardware load balancer

Artifacts:
- OnlineShopping.war deployed to WebServer
- DatabaseSchema.sql deployed to DatabaseServer

Connections:
- WebServer <---> DatabaseServer (JDBC)
- LoadBalancer --> WebServer (HTTP)
