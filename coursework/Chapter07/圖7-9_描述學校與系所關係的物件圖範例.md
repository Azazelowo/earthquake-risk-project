# Figure 7-9 Example Object Diagram showing School and Department relationships

This object diagram illustrates a specific school (National Kaohsiung University of Science and Technology) and its departments (Department of Computer Science, Department of Electrical Engineering).

- Object `school: School`: name = "National Kaohsiung University of Science and Technology", address = "Nanzih District, Kaohsiung"
- Object `dept1: Department`: name = "Department of Computer Science", code = "CS", part of school
- Object `dept2: Department`: name = "Department of Electrical Engineering", code = "EE", part of school
- Associations: school comprises dept1 and dept2 (aggregation)
