# 表7-2 行為塑模視圖用途與組成

| 視圖 | 用途 | 使用元素 |
|------|------|----------|
| 使用案例圖 | 描述系統的功能需求及與外部行為者的互動。 | 行為者（Actor）、使用案例（Use Case）、關聯（Association）、泛化（Generalization）、包含（Include）、擴展（Extend） |
| 資訊流程圖 | 展示資訊在系統內部或與外部實體間的流動。 | 實體（Entity）、資料儲存（Data Store）、處理程序（Process）、資料流（Data Flow） |
| 活動圖 | 描述工作流程中的活動及其排序、條件、並行。 | 活動（Activity）、活動狀態（Activity State）、決策節點（Decision Node）、合併節點（Merge Node）、分叉節點（Fork Node）、連接節點（Join Node）、時間事件（Time Event）、接受事件（Accept Event）、發送訊號（Send Signal）、接收訊號（Receive Signal） |
| 狀態機圖 | 描述物件在生命週期中狀態的變化及觸發事件。 | 狀態（State）、初始狀態（Initial State）、終止狀態（Final State）、事件（Event）、轉移（Transition）、動作（Action）、守衛條件（Guard） |
| 行為狀態圖 | 描述系統的行為狀態及其轉移條件。 | 行為狀態（Behavioural State）、事件（Event）、轉移（Transition）、條件（Condition） |
| 輪廓狀態圖 | 描述狀態機的輪廓（抽象）狀態，用於頂層行為描述。 | 輪廓狀態（Outline State）、事件（Event）、轉移（Transition） |
| 溝通圖 | 強調物件間的通訊關係而非時間順序。 | 物件（Object）、連結（Link）、訊息（Message） |
| 時序圖 | 顯示物件之間的互動及時間順序。 | 物件（Object）、生命線（Lifeline）、訊息（Message）、啟動棒（Activation）、時間限制（Time Constraint） |
| 互動概觀圖 | 提供互動流程的概觀，類似活動圖但使用互動片段。 | 互動（Interaction）、決策節點、合併節點、分叉節點、連接節點、時間事件、接受事件、發送訊號、接收訊號 |
