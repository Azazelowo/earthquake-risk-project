# OOP 語言特性表（參考 Table 3-2）

| 特性 | 說明 | 範例語言 |
|------|------|----------|
| 封裝 (Encapsulation) | 將資料與行為綁定在物件內部，透過方法控制存取，隱藏實作細節。 | Java, C#, Python |
| 繼承 (Inheritance) | 子類別繼承父類別的屬性與方法，可重用程式碼並建立階層關係。 | Java, C++, Python |
| 多型 (Polymorphism) | 同一方法呼叫在不同物件上會有不同行為，分為編譯時多型（過載）與執行時多型（覆寫）。 | Java, C#, Python |
| 抽象 (Abstraction) | 定義抽象類別或介面，僅宣告行為而不實作，由子類別具體實作。 | Java, C#, Python |
