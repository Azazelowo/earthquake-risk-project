# RUP 階段與目標表（參考 Fig3-13）

| 階段 | 主要目標 | 關鍵里程碑 |
|------|----------|------------|
| 初始 (Inception) | - 定義商業案例與範圍。<br>- 辨識關鍵需求與風險。<br>- 建立初始架構與計畫。 | 生命週期目標 (Lifecycle Objectives) 里程碑 |
| 精化 (Elaboration) | - 分析問題域與架構基礎。<br>- 解決高風險元素。<br>- 建立可驗證的架構原型。 | 生命週期架構 (Lifecycle Architecture) 里程碑 |
| 建構 (Construction) | - 建構完整的系統功能。<br>- 確保品質與效能達標。<br>- 準備好系統以供移轉。 | 初始運作能力 (Initial Operational Capability) 里程碑 |
| 移轉 (Transition) | - 將系統移交給使用者。<br>- 提供培訓與支援。<br>- 修正缺陷並達成最終使用者滿意度。 | 產品上市 (Product Release) 里程碑 |
