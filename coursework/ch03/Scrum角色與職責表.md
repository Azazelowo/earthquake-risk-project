# Scrum 角色與職責表（參考 Fig3-9 及相關說明）

| 角色 | 主要職責 |
|------|----------|
| 產品擁有者 (Product Owner) | - 負責產品待辦清單（Product Backlog）的內容、優先순위與價值最大化。<br>- 與利害關係人溝通，澄清需求並設定目標。<br>- 確保開發團隊理解待辦項目。 |
| Scrum 主管 (Scrum Master) | - 促進 Scrum 過程，移除團隊遇到的障礙。<br>- 確保團隊遵守 Scrum 原則與實踐。<br>- 指導團隊自我組織與跨功能合作。 |
| 開發團隊 (Development Team) | - 負責將產品待辦清單項目轉換為可增量的「完成」工作。<br>- 具備跨功能能力（設計、開發、測試等）。<br>- 自我組織，決定如何完成工作，並在每日站會中報告進度。 |
