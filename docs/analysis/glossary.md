# 詞彙表 (Glossary)

以下詞彙為本專題常用之專業術語，方便讀者快速了解。

| 詞彙 | 全稱 | 說明 |
|------|------|------|
| CWA | 中央氣象署 | 臺灣氣象業務主管機關，提供地震目錄與氣象觀測資料。 |
| ML | 地方規模 (Local Magnitude) | 以測站觀測到的地震波振幅計算之規模，適用於近距離地震。 |
| GPS 變形 | Global Positioning System Deformation | 透過衛星定位測量地殼形變，單位通常為 mm/yr。 |
| TEC | 電離層總電子含量 (Total Electron Content) | 電離層中電子數量之積量，單位 TECU (10^16 電子/米²)。 |
| 地磁 | Geomagnetic Observation | 測量地球磁場變化，單位納特斯拉 (nT)。 |
| 地下水層水位 | Groundwater Level | 地下水位高度，單位公尺 (m)。 |
| 大氣壓力 | Atmospheric Pressure | 大氣壓力，單位百帕斯卡 (hPa)。 |
| 雨量 | Rainfall | 降水量，單位毫米 (mm)。 |
| 潮汐 / 水載荷 | Tidal & Water Loading | 海洋潮汐引起的地殼壓力變化，單位千帕斯卡 (kPa)。 |
| 地殼應變/應力 | Crustal Strain/Stress | 地殼形變與內部應力，單位微應變 (με) 或帕斯卡 (Pa)。 |
| 風險指數 (Risk Score) |  | 依加權和或規則計算之 0~100 數值，代表相對地震風險。 |
| 基線值 (Baseline) |  | 最近 30 天區域平均之 ML、深度或震頻，作為風險評估參考。 |
| 權重 (Weight) |  | 各前驅資料在風險評分中的相對重要性，總和為 1。 |
| 正規化 (Normalization) |  | 將不同單位或範圍之特徵轉換至共同區間 (如 0~1)，以便加權和。 |
| UML | Unified Modelling Language | 軟體系統分析與設計之標準建模語言。 |
| SDLC | System Development Life Cycle | 系統開發生命週期，包含規劃、分析、設計、實作、測試、維護等階段。 |
| DFD | Data Flow Diagram | 資料流程圖，用於描述系統內資料之流動與處理。 |
| ERD | Entity-Relationship Diagram | 實體關聯圖，用於描述資料庫資料結構。 |
| GitHub Actions |  | GitHub 提供之持續整合與持續部署 (CI/CD) 服務。 |
| FOSS | Free and Open Source Software | 自由及開源軟體，如 Python、matplotlib 等。 |

--- 
*此詞彙表依據系統分析與設計第一章之術語說明原則編寫。*
