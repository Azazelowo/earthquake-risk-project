## 2. 既有的回測結果（讀 `docs/reports/hazard_precursor_mag/README.md`）

- 設定：預報窗 7 天；訓練 2020-11-01～2024-01-01，測試 2024-01-01～2026-09-20；有完整地磁特徵的格窗只佔 56.2%。
- **主要檢定**（事先指定）：M≥3.5、全部 6 個特徵，測試期資訊增益 **−0.0201 nat**，p＝**0.458**（循環平移 200 次）。
- 提高規模門檻後測試增益更差：M≥4 為 −0.2326、M≥5 為 −0.4871、M≥5.5 為 −0.9084；輔助檢定共 7 個，個別的小 p 值要考慮多重比較。
- 報告自己列出的限制：測站只有 3–5 個、測試期包含 2024 年花蓮序列、風險函數本身的偏差可能被有時間結構的特徵「撿到」、花蓮與台東測站不能用。
- 結論（照報告）：**沒有證據顯示地磁特徵讓預報變準**。這不等於「地磁沒有任何訊息」，只是這個資料量與這個做法下沒有檢出。

> 早先口頭引用過「增益約 −0.021、p≈0.50」，與報告的實際數字（−0.0201、0.458）有出入，**以報告為準**。

## 4. 決定（本次實作範圍）

1. **地磁**：做「只展示、不計入機率」的輸出 `precursors.json`（`app/export_precursors.py`），並固定帶回測的實際數字。
2. **TGM／TECDC／IESDMC**：不進實作。TGM 只到 2024 年、其餘沒有確認有前兆時間序列；先把待查項留著。
3. **活動斷層圖層**：**不做**。原因：沒有查到可下載的向量檔與授權；沒有授權依據就不應該把斷層線放進 APP。若使用者之後取得官方向量檔與授權說明，再簡化成 GeoJSON（小於 300 KB）放 `app/data/`。
4. **TEC**：待查本機輸出，本次不處理。

## 5. 怎麼驗證（給使用者或下一個工作階段）

- 活動斷層向量檔：到 `https://data.gov.tw` 搜尋「活動斷層」，看是否有中央地質調查所提供的 shp／GeoJSON 與授權說明；或用 `fault.gsmma.gov.tw` 的「聯絡我們」詢問。
- TGM 2025 年以後的資料：登入 TGM 官網的下載頁查看資料集版本與涵蓋年份（需要註冊，我不代為註冊）。
- IESDMC／TECDC：在瀏覽器逐項看資料目錄，記錄每個資料集的格式、涵蓋年份、授權；沒讀到的不要寫成事實。

```bash
python app/export_precursors.py --out app/data/precursors.json
```
