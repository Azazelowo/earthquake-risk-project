# 分段完備規模（Mc）

> 由 `pipeline/src/04_estimate_mc.py` 產生（2026-11-10）。對應 FR-B2-20（PROJECT_OVERVIEW 3.2）。

## 1. 結論

- 目錄特徵門檻改成**隨年份變動**：37 年中有 6 年要高於 ML 3.0，最高 3.7（見 `pipeline/configs/feature_min_ml_by_year.csv`）。
- 第 Y 年的門檻由第 Y−1 年（事件不夠時往前併到最多 5 年）各區 Mc 的最大值決定，不使用當年之後的資料。
- 粗體 = Mc 高於原本的固定門檻 3.0：這些「年 × 區」的 ML ≥ 3.0 事件不完整。

## 2. 資料與方法

- GDMS 原始目錄 12 個檔，研究區內、Gap ≤ 110 或未知、來源內去重後 287,534 筆（**不**先刪 ML < 2）。
- MAXC = 0.1 級距直方圖的眾數 + 0.2；GFT90 = 擬合度 R ≥ 90% 的最小 Mc（Wiemer & Wyss 2000）。Mc = 兩者較大者。某「年 × 區」事件不到 200 筆時往前併年（最多 5 年，見 CSV 的 `pool_years`），仍不夠則不估。
- 分區（粗略）：東部外海 lon ≥ 121.8；西部外海 lon < 120.2；南部外海 lat < 21.9；其餘為本島。東部外海的界線會包到宜蘭、花蓮海岸的一小部分陸地。
- MAXC 自助法 200 次的標準差見 CSV 的 `mc_maxc_sd`，多數在 0.1 左右。

**外海早期事件太少**：1990 年代東部外海通過 Gap ≤ 110 的事件十年不到 30 筆，併 5 年也估不出 Mc。這時外海的問題不是「Mc 偏高」，而是**定位品質篩選把大部分外海事件刪掉了**，影響比 Mc 大得多。目錄特徵用同一套篩選，所以早期外海網格的特徵主要來自鄰近的陸地事件；B3 用「占全區比例」特徵、目標事件不看 Gap，就是為了減輕這個偏差。

## 7. 限制

- MAXC 在事件少或分布不平滑時會低估 Mc，所以加 0.2，並取和 GFT90 的較大者。
- 分區是經緯度直線切，不是依測網幾何；更細的空間 Mc（例如 0.5° 格）事件數不夠，不估。
- 門檻隨年份改變後，同一時間點的各網格仍用同一個門檻，「占全區比例」特徵才可以比較。只有視窗跨年（例如 365 天）時，一個視窗內會混到兩個門檻。
