# 大地震剛發生後，模型反應得夠不夠快

> 由 `pipeline/src/08_mainshock_response.py` 產生。重新執行會覆寫本檔。

測試期（2015-01-01 起）每個 M≥6 地震（39 個，定位良好的母體），在主震後固定延遲發布一次，看震央 50 km 內的預測。預測含滾動校準，和 APP 的即時更新相同。

- **預測÷實際**：之後 1 天／7 天的 M≥3.5 地震數，所有主震加總後相除。< 1 = 低估。
- **倍數**：3 天、M≥5 的機率 ÷ 只有背景的機率（APP 首頁的數字），取所有主震的中位數。

## 參數

- **v1.1**：alpha = 0、d_frac = 0、p = 0.7、sigma_st = 0.5、K = 0.04371
- **v1.2**：alpha = 0.8、d_frac = 0、p = 0.7、sigma_st = 0.5、K = 0.04371

## 解讀時要注意

- 主震數量少，彙總數字受最大的幾個序列主導（2018、2022、2024 年）。
- 實際數量來自目前的完整目錄；即時運作時主震後的目錄還沒更新，APP 實際看到的會更低，因為即時資料只補得到有感報告與 USGS（見資料缺口評估）。
- 這只檢查主震之後；主震之前模型沒有能力指出哪一次地震會成為大地震。
