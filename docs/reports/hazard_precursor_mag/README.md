# 地磁能不能讓風險函數更準：檢定報告

> 由 `pipeline/src/07_hazard_precursor.py` 產生（2026-11-17 21:59）。重新執行會覆寫本檔。

## 問題與做法

把地磁特徵當成風險函數發生率的倍率，看測試期的預報有沒有變準。樣本是全部 M≥3.5 的地震（不是只有大地震），
所以有足夠的數量做檢定；再把規模門檻提高，檢查「只有大地震才看得到地磁影響」的猜想。

- 預報窗 7 天；訓練 2020-11-01 ～ 2024-01-01，測試 2024-01-01 ～ 2026-09-20
- 事件母體：located（125,524 / 125,728 筆），和風險函數的參數一致
- 特徵：每格在發布時間之前 7 天、30 天的平均 z 值（相對其他測站、扣除 Kp、Dst、極化比），共 6 個
- 有完整地磁特徵的格窗：56.2%（其餘離測站超過 150 km 或資料不足，不納入）
- **資訊增益**：每個測試期地震平均多得到的資訊（nat）。0 = 和沒加地磁一樣；負值 = 加了反而變差。
- **p 值**：把地磁特徵沿時間整段循環平移 200 次後重做，平移結果不輸真實結果的比例。p 小於 0.05 才算不像碰巧。

## 限制

1. 地磁只有 3–5 個測站，每格取最近的測站，所以同一測站涵蓋的格子特徵幾乎相同，獨立資訊比格窗數少得多。
2. 測試期包含 2024-04 花蓮地震序列，地震高度群聚；增益可能被少數幾週主導。循環平移保留了這個結構，所以 p 值仍可參考，但增益的大小不穩定。
3. 風險函數本身的偏差（例如餘震期低估）可能被任何有時間結構的特徵「撿到」，這不代表該特徵是前兆。
4. 「相對其他測站」會扣掉涵蓋全台的訊號；用遠端參考站（鹿屋）的版本還沒做。
5. 花蓮、台東測站不能用，東部外海離測站遠，覆蓋不到。
