### UC-01 所在地風險查詢

| 項目 | 內容 |
|---|---|
| 1 名稱 | 所在地風險查詢 |
| 2 簡要描述 | 民眾開啟 APP 後，系統以目前位置為圓心，計算預設條件下的地震機率，並和平常比較 |
| 3 主要參與者 | A1 一般民眾 |

| 7 後置利益 | 畫面顯示狀態（倍數與顏色）、現在與平常的機率、驗證標籤；位置降低精度後存在本機 |
| 8 觸發 | 開啟 APP（E-01）；或在選位置面板按「使用目前位置」（E-02） |
| 9 正常情節 | 見 1.4.1 |
| 10 例外、替代 | 見 1.4.3 |
| 11 補充 | 定位只用低精度（`main.ts:164-165`）；位置不外送 |

**1.1 前置條件**：使用說明已確認（UC-10），或這次開啟已經按過「我了解」。
**1.2 後置條件**：`s.place` 已更新；`localStorage` 裡的座標精度為 0.01°（`state.ts:103-107`）。
**1.3 擴充點**：使用說明確認（UC-10）；矇中機率轉送（UC-13）。

**1.4.1 基本流程**
1. 民眾開啟 APP。
2. 系統顯示使用說明（第一次開啟時），民眾按「我了解」。
3. 系統向瀏覽器要求位置（低精度、8 秒逾時）。
4. 系統取得座標，先顯示「目前位置」。
5. 系統計算範圍機率（include UC-16）：網格權重 → 期望次數 → 換算規模 → 卜瓦松機率。
6. 系統判斷鄉鎮區（include UC-17），把標籤更新成「XX 市 XX 區」或「XX 區附近」。
7. 系統顯示狀態等級（`format.ts:12-21`）、倍數、現在與平常的機率、「已驗證」或「外推估計」。

**1.4.2 子流程**：無。

**1.4.3 替代流程**
- 3a. 定位被拒絕或逾時：使用上次的位置或預設的高雄市，並顯示「無法定位，暫用這個位置」（`public.ts:37`）。
- 5a. 圓心在網格外，或涵蓋率 < 50%：不顯示數字，改顯示「目前模型未涵蓋此區域」（`public.ts:81-90`）。
- 6a. 界線檔載入失敗（例如第一次開啟就離線）：改說「最近的縣市＋附近」（`main.ts:125-129`）。
- 5b.（**規劃中，目前缺漏**）feed 超過 2 小時沒有更新：標成「已過期」。

**26.4.1 基本流程**（`06_hazard_model.py:186-234`）：
